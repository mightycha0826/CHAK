# 무대 표지 사진

온보딩 첫 화면의 배경. 여기에 파일을 넣으면 바로 적용된다.

| 파일 | 무대 |
|---|---|
| `hcs.jpg` | 현충사 |
| `ss.jpg` | 신라스테이 천안 |

**없어도 앱은 정상 동작한다.** 파일이 없거나 로드에 실패하면 검정 화면으로
떨어진다 — 발표장에서 이미지 하나 때문에 첫 화면이 깨지면 안 되니까.

## 권장 사양

- 가로 사진이면 1600px 이상, 세로로 길게 잘려도 피사체가 남는 구도
- JPEG, 300KB 이하 (첫 화면이라 로딩이 곧 첫인상이다)

## 잘리는 위치 조정

세로 화면에 가로 사진을 담으면 좌우가 크게 잘린다. 어디를 남길지는
`src/content/stages/<무대>.ts`의 `cover.position` 한 줄로 정한다
(CSS `object-position` 값).

```ts
cover: { src: '/covers/hcs.jpg', position: '26% 40%' },
//                                          ↑ 가로 기준점. 낮출수록 왼쪽이 남는다
```

현충사 사진은 동상이 왼쪽에 있어 `26%`로 잡아 두었다. 동상이 더 크게
나오길 원하면 `18%`, 본전 건물을 더 담고 싶으면 `40%` 쪽으로 옮기면 된다.

출처를 화면에 남기려면 `cover.credit`을 채운다 — 표지 하단에 작게 붙는다.

## 저작권

경진대회 제출물이라면 사진 출처를 반드시 확인할 것. 뉴스·블로그 이미지는
대개 사용할 수 없다. 안전한 쪽:

- **공공누리** (kogl.or.kr) — 현충사관리소·국가유산청 사진이 제1유형으로 다수 공개
- **한국관광공사 포토코리아** (kto.visitkorea.or.kr)
- 직접 촬영
